# Canonical project naming

- The project's only canonical public name is **Luma**.
- Treat every earlier working title as retired internal history.
- Never reproduce, suggest, cite, or introduce a retired working title in prose, code comments, documentation, diagrams, filenames, UI copy, commit messages, or generated artifacts.
- When editing existing materials, replace a retired project title with **Luma** unless the user explicitly requires an immutable historical quotation.
- If an existing source conflicts with this rule, preserve the source file when necessary but use **Luma** in all newly generated or revised material.
