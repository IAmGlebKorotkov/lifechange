# Функциональные и нефункциональные требования.docx

## Paragraphs

P0001 [normal] 1 Функциональные требования
P0002 [normal] Регистрация и авторизация:
P0003 [normal] При регистрации пользователь должен указать имя, дату рождения, адрес электронной почты и пароль.
P0004 [normal] Поля не должны оставаться пустыми, пароль должен содержать не менее шести символов.
P0005 [normal] Для авторизации пользователь должен ввести адрес электронной почты и пароль.
P0006 [normal] После успешной авторизации приложение должно сохранять пользовательскую сессию, чтобы исключить повторный ввод учетных данных при каждом запуске.
P0007 [normal] Пользователь имеет возможность включить вход с помощью распознавания лица.
P0008 [normal] Если Face ID недоступен или распознавание лица завершилось неудачно, пользователь должен иметь возможность войти с помощью электронной почты и пароля.
P0009 [normal] Пользователь должен иметь возможность завершить текущую сессию и вернуться на экран авторизации.
P0010 [normal] Навигация между разделами приложения:
P0011 [normal] Навигация должна осуществляться с помощью нижней панели вкладок TabBar и должна иметь пять разделов: Календарь, Дневник, Анализ дня, Статистика и Профиль.
P0012 [normal] Отображение календаря и списка задач:
P0013 [normal] Календарь должен предоставлять пользователю возможность выбирать дату и просматривать запланированные на нее задачи и события.
P0014 [normal] Для выбранного дня необходимо отображать количество выполненных элементов и общее количество запланированных дел.
P0015 [normal] Задачи и события должны быть отсортированы по времени начала.
P0016 [normal] Пользователь должен иметь возможность фильтровать элементы по состоянию выполнения: «Все», «Выполняемые» и «Завершенные».
P0017 [normal] Для сложных задач фильтрация должна применяться для подзадач сложной задачи.
P0018 [normal] Выполненные задачи и подзадачи должны учитываться при расчете общего прогресса за день.
P0019 [normal] В календаре необходимо совместно отображать задачи, созданные внутри приложения, и события из системного календаря iOS.
P0020 [normal] Доступ к системному календарю должен запрашиваться только с разрешения пользователя.
P0021 [normal] При изменении событий системного календаря или возвращении приложения в активное состояние список должен автоматически обновляться.
P0022 [normal] Для собственных задач пользователь должен иметь возможность изменять название, описание, важность и сложность, отмечать задачу выполненной и удалять ее.
P0024 [normal] Создание задач и событий:
P0025 [normal] В приложении можно будет создать обычные задачи, сложные задачи и события с фиксированным временем.
P0026 [normal] Для каждого элемента пользователь должен указать название, важность и сложность.
P0027 [normal] Для события пользователь должен указать точное время начала и окончания.
P0028 [normal] Для задачи пользователь должен указать период выполнения в виде дат и предполагаемую продолжительность.
P0029 [normal] Приложение не может сохранять элемент без названия.
P0030 [normal] Время окончания события не должно предшествовать времени его начала.
P0031 [normal] Минимальная продолжительность одного запланированного блока должна составлять 15 минут.
P0033 [normal] Создание события:
P0034 [normal] Событие должно сохраняться на выбранное пользователем время без автоматического переноса.
P0035 [normal] При отображении события в календаре необходимо показывать его название, время начала и окончания.
P0036 [normal] Событие должно учитываться как занятый интервал при автоматическом планировании других задач.
P0038 [normal] Автоматическое планирование обычной задачи:
P0039 [normal] Для обычной задачи пользователь должен указать период, в пределах которого она должна быть выполнена.
P0040 [normal] После создания задачи приложение самостоятельно выбирает подходящий свободный интервал с помощью алгоритма.
P0041 [normal] При составлении плана необходимо учитывать существующие задачи и события системного календаря.
P0042 [normal] Запланированные задачи не должны пересекаться с уже занятыми временными интервалами.
P0043 [normal] При выборе времени необходимо учитывать важность, сложность и предполагаемую продолжительность задачи.
P0044 [normal] Важные и сложные задачи должны по возможности размещаться в более ранних временных интервалах.
P0045 [normal] Если в указанном периоде отсутствует подходящий свободный интервал, приложение должно выбрать ближайшее доступное время.
P0047 [normal] Создание и планирование сложной задачи:
P0048 [normal] Пользователь имеет возможность разделить сложную задачу на подзадачи.
P0049 [normal] Сложная задача должна содержать как минимум одну подзадачу.
P0050 [normal] Для каждой подзадачи необходимо указывать собственное название, важность, сложность и предполагаемую продолжительность.
P0051 [normal] Описание подзадачи является необязательным.
P0052 [normal] Пользователь должен иметь возможность добавлять и изменять подзадачи до сохранения сложной задачи.
P0053 [normal] Приложение должно автоматически распределять подзадачи внутри общего периода выполнения сложной задачи.
P0054 [normal] При распределении подзадач необходимо учитывать занятые интервалы, важность, сложность и продолжительность каждой подзадачи.
P0055 [normal] Подзадачи не должны пересекаться друг с другом и с уже запланированными элементами.
P0056 [normal] После распределения приложение должно сформировать итоговый план сложной задачи.
P0058 [normal] Ограничения автоматического планирования:
P0059 [normal] Планирование задач должно преимущественно выполняться в промежутке с 08:00 до 23:00.
P0060 [normal] Если выполнение задачи выходит за установленную границу дня, приложение должно предложить пользователю разделить ее.
P0061 [normal] При согласии пользователя оставшаяся часть задачи должна быть перенесена на следующей дня.
P0062 [normal] Перенесенная часть должна отображаться в календаре как продолжение исходной задачи.
P0063 [normal] Уведомления:
P0064 [normal] Пользователь должен иметь возможность включать и выключать уведомления в настройках профиля.
P0065 [normal] При первом включении уведомлений приложение должно запросить системное разрешение на их отправку.
P0066 [normal] Если пользователь включил уведомления, но не разрешил доставку уведомлений, приложение должно сообщить о необходимости изменить настройки iOS.
P0067 [normal] Для запланированных задач необходимо создавать уведомления за 30 и за 5 минут до начала выполнения.
P0068 [normal] Для сложной задачи уведомления должны создаваться отдельно для каждой подзадачи.
P0069 [normal] Приложение должно отправлять напоминания о заполнении дневника сна в 08:00 и 12:00, если пользователь не заполнил его ранее.
P0070 [normal] Напоминания о заполнении дневника эмоций должны отправляться в 18:00 и 20:00.
P0071 [normal] После заполнения соответствующего дневника оставшиеся напоминания на текущий день должны быть отменены.
P0072 [normal] Пользователь должен иметь возможность просматривать доставленные уведомления на отдельном экране.
P0073 [normal] Уведомления должны отображаться в обратном хронологическом порядке.
P0074 [normal] При отключении уведомлений все запланированные приложением напоминания должны быть отменены.
P0075 [normal] Дневник эмоций и сна:
P0076 [normal] Дневник должен содержать два вида записей: эмоциональное состояние и сведения о сне.
P0077 [normal] Все записи должны сохраняться с привязкой к текущему пользователю и дню.
P0078 [normal] Сохраненные записи должны использоваться при построении статистики и выполнении анализа состояния пользователя.
P0079 [normal] Дневник эмоций:
P0080 [normal] При заполнении дневника пользователь должен иметь возможность выбрать эмоцию из предложенного перечня: радость, грусть, злость, тревога, покой и любовь.
P0081 [normal] Для каждой выбранной эмоции пользователь должен указать интенсивность по десятибалльной шкале.
P0082 [normal] Пользователь должен иметь возможность дополнительно указать текстовое описание причины эмоционального состояния.
P0083 [normal] Описание причины является необязательным.
P0084 [normal] После сохранения записи приложение должно отменить оставшиеся уведомления о заполнении дневника эмоций на текущий день.
P0086 [normal] Дневник сна:
P0087 [normal] Пользователь должен указать время отхода ко сну и время пробуждения.
P0088 [normal] На основании введенных значений приложение должно автоматически определять продолжительность сна.
P0089 [normal] После сохранения записи приложение должно отменить оставшиеся уведомления о заполнении дневника сна на текущий день.
P0090 [normal] Режим фокусировки:
P0091 [normal] Пользователь имеет возможность выбрать одну из незавершенных задач или подзадач текущего дня.
P0092 [normal] Продолжительность сеанса фокусировки должна определяться предполагаемой продолжительностью выбранной задачи.
P0093 [normal] Перед началом сеанса пользователь имеет возможность выбрать музыкальный плейлист или режим без музыкального сопровождения.
P0094 [normal] После запуска сеанса приложение должно начать обратный отсчет оставшегося времени.
P0095 [normal] Во время сеанса должна воспроизводиться музыка из выбранного плейлиста.
P0096 [normal] После окончания сеанса музыкальное воспроизведение должно быть остановлено.
P0097 [normal] Информация о продолжительности сеанса должна сохраняться для расчета статистики и прогресса достижений.
P0098 [normal] После завершения сеанса выбранная задача должна быть отмечена выполненной.
P0099 [normal] Отображение сеанса через Live Activity:
P0100 [normal] Во время работы режима фокусировки приложение должно создавать Live Activity.
P0101 [normal] Live Activity должна отображаться на экране блокировки и в Dynamic Island на поддерживаемых устройствах.
P0102 [normal] В Live Activity необходимо показывать название и тип выбранной задачи, а также оставшееся время.
P0103 [normal] Пользователь должен иметь возможность завершить задачу непосредственно из Live Activity.
P0104 [normal] После окончания или принудительного завершения сеанса Live Activity должна быть закрыта.
P0105 [normal] Анализ состояния пользователя:
P0106 [normal] Приложение должно выполнять анализ состояния пользователя на основании задач, записей сна и эмоционального дневника.
P0107 [normal] При расчете необходимо учитывать продолжительность сна, эмоциональное состояние, количество выполненных и оставшихся задач, их важность, сложность и предполагаемую продолжительность.
P0108 [normal] События системного календаря должны учитываться при определении занятого и доступного времени.
P0109 [normal] При анализе необходимо учитывать наличие просроченных задач и нагрузку следующего дня.
P0110 [normal] Результатом анализа должны являться оценки ресурса, нагрузки и баланса пользователя по шкале от 0 до 100.
P0111 [normal] Приложение должно определять уровень нагрузки пользователя: низкий, сбалансированный, высокий или перегрузка.
P0112 [normal] Необходимо отображать степень точности анализа, зависящую от количества доступных данных.
P0113 [normal] При недостаточном количестве записей результат должен обозначаться как предварительный.
P0114 [normal] По результатам анализа приложение должно формировать краткое описание состояния пользователя.
P0115 [normal] Приложение должно формировать не более четырех персональных рекомендаций.
P0116 [normal] Рекомендации могут быть связаны с недостатком сна, высокой нагрузкой, просроченными задачами, эмоциональным напряжением или необходимостью переноса части дел.
P0117 [normal] Общая статистика:
P0118 [normal] На экране общего анализа необходимо отображать показатели пользователя за последние семь дней.
P0119 [normal] Статистика должна содержать количество выполненных и общее количество запланированных задач.
P0120 [normal] Необходимо отображать показатели качества сна, эффективности выполнения задач и эмоционального состояния.
P0121 [normal] Эффективность должна рассчитываться с учетом продолжительности, важности и сложности выполненных задач.
P0122 [normal] Подробная статистика:
P0123 [normal] Подробная статистика должна быть разделена на категории «Эмоции», «Сон» и «Задачи».
P0124 [normal] В разделе эмоций необходимо отображать преобладающую эмоцию за последние 30 дней, распределение эмоциональных записей и их среднюю интенсивность.
P0125 [normal] В разделе эмоций также необходимо показывать динамику состояния за последние семь дней и историю последних записей.
P0126 [normal] В разделе сна необходимо отображать дату записи, время засыпания, время пробуждения и продолжительность сна.
P0127 [normal] В разделе задач необходимо отображать статистику выполнения дел за последние 30 дней.
P0128 [normal] Для каждого дня необходимо показывать количество выполненных и общее количество запланированных задач.
P0129 [normal] Пользователь должен иметь возможность открыть день и просмотреть подробный состав выполненных и невыполненных задач.
P0130 [normal] Достижения:
P0131 [normal] В приложении должна быть реализована система достижений, предназначенная для дополнительной мотивации пользователя.
P0132 [normal] Условия получения достижений должны быть связаны с выполнением задач, ведением дневника сна и эмоций, соблюдением продолжительности сна и использованием режима фокусировки.
P0133 [normal] Для каждого достижения необходимо отображать название, описание цели, текущее значение и требуемое значение.
P0134 [normal] Достижение может находиться в заблокированном, разблокированном или открытом состоянии.
P0135 [normal] После выполнения условия пользователь должен иметь возможность открыть достижение и получить опыт.
P0136 [normal] Прогресс достижений должен автоматически обновляться при изменении задач, записей дневника и продолжительности фокус-сессий.
P0137 [normal] Система уровней:
P0138 [normal] За каждое открытое достижение пользователю должно начисляться 50 единиц опыта.
P0139 [normal] После накопления 250 единиц опыта пользователь должен переходить на следующий уровень.
P0140 [normal] Для каждого уровня должно быть предусмотрено соответствующее звание.
P0141 [normal] Текущий уровень, звание и прогресс до следующего уровня должны отображаться на экране достижений и в профиле пользователя.
P0142 [normal] Профиль пользователя:
P0143 [normal] В профиле необходимо отображать имя пользователя, адрес электронной почты, скрытое представление пароля, аватар, текущий уровень и количество накопленного опыта.
P0144 [normal] Пользователь должен иметь возможность выбрать изображение профиля из медиатеки устройства.
P0145 [normal] В профиле необходимо разместить настройки Face ID и уведомлений.
P0146 [normal] Настройка Face ID должна отображаться только на устройствах, поддерживающих данную технологию.
P0147 [normal] Пользователь должен иметь возможность выйти из учетной записи после подтверждения действия.
P0148 [normal] 2 Нефункциональные требования
P0149 [normal] Требования к платформе и совместимости:
P0150 [normal] Приложение должно быть реализовано как нативное мобильное приложение для операционной системы iOS.
P0151 [normal] Интерфейс должен корректно отображаться на поддерживаемых моделях iPhone и iPad с различными размерами экранов.
P0152 [normal] Для интеграции с возможностями устройства должны использоваться стандартные средства iOS.
P0153 [normal] Функции Face ID и Live Activity должны отображаться только на устройствах, которые их поддерживают.
P0154 [normal] Отсутствие Face ID, Live Activity или разрешения на доступ к системному календарю не должно препятствовать использованию остальных функций приложения.
P0155 [normal] Приложение не должно завершать работу при отсутствии или отзыве системного разрешения.
P0156 [normal] Требования к пользовательскому интерфейсу:
P0157 [normal] Интерфейс приложения должен быть выполнен в едином визуальном стиле.
P0158 [normal] Названия разделов, кнопок и полей должны однозначно отражать их назначение.
P0159 [normal] Основные разделы приложения должны быть доступны с помощью постоянной панели TabBar.
P0160 [normal] Переход к любому основному разделу должен выполняться одним нажатием.
P0161 [normal] Формы ввода должны содержать подсказки и визуально обозначать обязательные поля.
P0162 [normal] При отсутствии задач, дневниковых записей, уведомлений или статистики приложение должно отображать понятное сообщение о том, что данные отсутствуют.
P0163 [normal] Ошибки ввода и выполнения операций должны сопровождаться сообщением с описанием причины.
P0164 [normal] Потенциально значимые действия, например выход из учетной записи, должны требовать подтверждения пользователя.
P0165 [normal] Основным языком пользовательского интерфейса должен быть русский.
P0166 [normal] Требования к доступности:
